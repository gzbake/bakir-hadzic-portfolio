# Bakir Hadžić — Portfolio

Single-page personal portfolio. Astro, TypeScript, GSAP, Three.js.

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Edit content

- About + contact: `src/data/site.ts`
- Experience: `src/data/experience.ts`
- Work gallery: `src/data/work.ts`

Drop images into `public/images/work/` using the filenames in `work.ts`.

## Tech

Astro · TypeScript · GSAP + ScrollTrigger · Three.js shader background
